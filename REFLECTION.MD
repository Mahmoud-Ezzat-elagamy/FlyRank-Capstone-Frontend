# Reflection

## What was the hardest thing?

The hardest part was finding a good idea. I wanted something that would help me personally and also help other people, and that had a real technical approach behind it. I didn't want to build yet another chatbot that takes a message and sends back a summary, because that is already done everywhere.

I had already started the project when I asked Claude about tools that could help, and that is how I learned that AI can generate diagrams (using Mermaid). I hadn't planned for this feature at all. Once I found out about it, I started implementing it, but it was hard to understand at first because it was my first time generating diagrams through AI in my own code.

## What would I do differently next time?

This time I came up with the idea and went straight into planning and implementation using only my own ideas, which limited how much the app could do. Next time, I will spend more time at the start discussing with Claude the possibilities that fit the context of my project. That way I can find useful features before I begin building, instead of discovering them halfway through.

## What surprised me

**1. How powerful AI is for coding.** Before this internship I didn't use AI much. Now I don't get stuck when I need to learn something new. I can focus on the idea and let AI help with the hard implementation. I also try to understand the code by asking it why it made each choice.

**2. That diagram generation is possible at all.** I had never heard of a tool that generates diagrams from text before this project.
